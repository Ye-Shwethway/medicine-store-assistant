# Daily Usage from Paper Form

Use this workflow when the user supplies a paper form, photo, scan, or transcription corresponding to `Daily Usage`.

## Read literally

Identify from the source:

- item or row,
- day/date column,
- quantity used,
- received-stock entry if present,
- remarks if present.

Inspect the live sheet so row and date-column alignment comes from current evidence. If handwriting, cell alignment, or the target lot is unclear, state the uncertainty instead of inventing a value.

## Record actual movement

If the form records usage against a particular row or expiry lot, write it to that corresponding row. Do not move it to an older or near-expiry lot to satisfy FIFO/FEFO. The source form is the historical movement evidence.

After faithfully recording the source, optionally warn about:

- newer batch used before older batch,
- near-expiry stock bypassed,
- apparently expired stock used,
- possible wastage risk.

Warnings never modify recorded usage.

## Verify and report

Read back the affected date cells and rows. Confirm exact values, row/lot targeting, formulas, visual marks, and unchanged neighboring cells. Report entered lines, unresolved fields, advisory warnings, and verification status.
